## 作品指纹

| 版本 | 日期 | 文件数 | 总指纹（SHA-256） |
|---|---|---|---|
| v1.0.0 | 2026-09-12 | 124 | `b26aa585a15c5cef7b4a3e7c006b6fc352c9600a3132f5747e62595f01c0d959` |

算法：对全部源文件逐个算 SHA-256，把「哈希 + 相对路径」按路径排序拼成一整块，
对这块整体再算一次 SHA-256。改一个字符、删一个文件，指纹都会变。

逐文件清单见 [provenance.sha256](provenance.sha256)（只有文件名与哈希，没有代码内容）。

核对方式：拿到代码后用作者提供的脚本重新生成清单，应与本仓库的
[provenance.sha256](provenance.sha256) 逐行一致。
